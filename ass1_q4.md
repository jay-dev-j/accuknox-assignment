# Assignment 1 - Q4: Most Complex Python Code

## Project: Malayalam Fake News Detection using mBERT

My most complex Python project is Malayalam Fake News Detection System using mBERT.

The project deals with predicting whether the Malayalam news is Fake or True using NLP based transformer based  model.

### Technologies used:

- Python
- Pandas
- Scikit-learn
- PyTorch
- Hugging Face Transformers
- mBERT (bert-base-multilingual-cased)
- Gradio (frontend)

### Main functionalities of the project:

- Malayalam dataset preparation and preprocessing
- Text classification
- Tokenization using Hugging Face tokenizers
- Fine-tuning of the mBERT model
- Model training & Evaluation of the model
- Fake/True Prediction
- User Interface (Gradio)

### GitHub Repository:

[Malayalam Fake News Detection using mBERT](https://github.com/jay-dev-j/malayalam-fake-news-transformer)

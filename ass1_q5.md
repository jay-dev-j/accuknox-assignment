# Assignment 1 - Q5: Most Complex Database Code

## Project: Cricbuzz Live Stats Analysis

My most complex project related to the database is Cricbuzz Live Stats Analysis.

In this project, the database is used to save the data related to cricket through the Cricbuzz API.

### Technologies Used

- Python
- MySQL
- Streamlit
- Cricbuzz API

### Features Related to Database

- Creation of MySQL database and configuring it
- Making tables in the database
- Saving cricket data in the database
- CRUD operations
- Fetching the data from the database
- Connecting the application with the MySQL database

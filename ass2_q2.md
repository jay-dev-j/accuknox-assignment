# Assignment 2 - Q2: 
An large language model chatbot is a chatbot that uses a Large Language Model to understand
the user's question and generate a response.

## Main Components

### 1. User Interface

This is where the user enters the question and receives the answer. It will helps user to understand things. 

### 2. Backend

The backend receives the user's message and sends it to the LLM.

### 3. LLM

The LLM understands the question and generates a best response.

### 4. Prompt

The user's question and instructions are given to the LLM as a prompt.

### 5. Conversation History

Previous messages can be stored and used to understand the context of the conversation with user.

### 6. Database

A database can be used to store user information and chat history.

## Basic Flow

User - Chat Interface - Backend - Prompt - LLM - ResponseUser

## Conclusion

The core concept is to get the input from the user, process it via the backend to the LLM and give back the output generated to the user. A conversation log and database can be used to make the chatbot even more useful.
